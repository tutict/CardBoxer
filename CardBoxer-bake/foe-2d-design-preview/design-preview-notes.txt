================================================================
日期：2026-11-07
需求：工程师「请给我看看对手怪的 2d 设计」


一、这是什么 / 不是什么
----------------------------------------------------------------
这是**展示整理**，不是重新出图、不是 3D 建模、不是游戏资产。
源图就是上一轮 `foe-model-probe-v1/concept-art/` 里那两张 ImageGen concept-art，
逐字节复制进本目录（sha256 已核对），只做缩放排版、按取景框裁细节、
抹掉右下角服务水印。**造型像素一个都没改。**

3D 探针当日 hy-3d 配额 5/5 用满、提交阶段 HTTP 429 被拒，
本目录里没有 GLB / 没有骨架 / 没有动画，全部是 2D 位图。

三、取景框是人工设计选择，不是测量结论
----------------------------------------------------------------
  六框按原图宽高的比例写在 `make_foe_design.py` 的 CROPS 和
  `design_stats.json` 里，可复算。选它们是为了让设计要点读得清，
  **不代表「检测到了某部件」**：
    head    (0.40, 0.02, 0.68, 0.25)   兜帽 / 全面罩 / 呼吸管
    crystal (0.13, 0.08, 0.41, 0.28)   单肩青色结晶簇
    chest   (0.27, 0.16, 0.73, 0.47)   胸甲 / 斜跨带 / 管线
    arms    (0.04, 0.29, 0.37, 0.63)   铆接护臂 / 缠手带
    belt    (0.19, 0.38, 0.77, 0.65)   工具腰带 / 挂包 / 垂牌
    boots   (0.11, 0.72, 0.90, 0.99)   警示条纹 / 护膝 / 厚底靴


四、抹水印：先证明抹的是纯背景，再抹
----------------------------------------------------------------
  框 `(881, 1436, 1024, 1536)`，填充色取该框正上方 24px 纯背景条带
  的均值 RGB `(202, 199, 197)`；不从左侧复制 —— 左侧同高度有靴子，
  会复制出一只假靴子。

  首次判据用「暗像素比例」判，**实测 0.0 → 0.0 整条空转**：水印是浅灰底
  上的白色字，不是深色字。改成「与背景填充色最大通道偏差 >12 的像素占比」：
    off_fill_before = 0.17224  →  off_fill_after = 0.0
  同时钉住 `dark_ratio_before = 0.0`：框里没有深色造型像素，
  填色没有覆盖到任何护甲 / 靴子。原图（含水印）仍完整保留可切换对照。

六、看图结论（人的判断）
----------------------------------------------------------------
  造型语言读得清：深兜帽 + 双圆镜片防毒全面罩 + 呼吸管；单肩青色发光
  结晶簇；错配铆接装甲板、斜跨带、圆盘机件与外露管线；厚重工具腰带、
  挂包、盘绕电缆、垂挂金属牌与破布下摆；超大铆接护臂 + 缠手带（无拳套）；
  橙黄警示斜纹、护膝、厚底钢头靴。炭黑 / 铁锈红 / 工业橙 + 一处电光青。
  无武器、无露肤，与玩家 V4b 的纤细浅色露脸长衫形成剪影与明度对立。

  如实偏差：规格要「单片裂纹护目镜」，生成成双圆镜片防毒面具；
  整体偏写实重甲插画，比 V4b 的二游 PBR 更硬，同屏是否协调要等
  3D 同相机渲染才能判；细节六格里「护臂」那格是竖长条，等比缩放后
  左右留白较多，属取景选择不是缺陷。
