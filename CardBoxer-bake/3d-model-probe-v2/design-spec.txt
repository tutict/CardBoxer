一、资料核对（多源，2026-11-07 查）
---------------------------------------------------------
一致结论（百度百科 / 360百科 / 搜狗百科 / newton.com.tw / 维基镜像 /
gintama.fandom.com / all-worlds-alliance.fandom.com / shapes.inc）：

  《银魂完结篇·永远的万事屋》（2013 剧场版，五年后时间线）的神乐：
    - 及腰长发，不再是日常的双包包头；右侧一个发髻 / 发夹
    - **白色长旗袍 / 白色中国风长衫**，高立领
    - **下摆一圈蓝色云纹** —— 花纹取自银时的浴衣 / 和服外套
      （百度百科「改装有银时浴衣上蓝色云纹的高开叉旗袍」、
        维基镜像「旗袍下摆的花色跟银时的和服外套一样」、
        360百科「一身浮云白衣和黑靴子算是继承了阿银的色彩」、
        fandom「long white cheongsam with red buttons, bottom decorated
        with the pattern seen on Gintoki's yukata」）
    - **红色盘扣 / 红纽扣**
    - 高开叉、黑靴、巨大的伞（几乎与身高等高）、登场时遮阳斗篷
    - 气质由「大大咧咧」转为冷感/沉静，身形高挑

冲突辨析（不采纳）：
  3loumao 那篇 cos 文写「白底红盘扣无袖上衣 + 蓝色护腰 + 黄色腰带 +
  黑色长手套 + 橘红长直发 + 紫伞」。这与上述 8 个来源的「白色长旗袍 +
  下摆蓝云纹」不是同一套，属 coser 混搭/另一时期服装，**不作依据**。


二、提取什么、舍弃什么（这是本轮真正的设计决策）
---------------------------------------------------------
  | 提取为服装语言 | 落到 V2 模型上 |
  |---|---|
  | 白色 / 米白长款立领长衫 | 主色由 V1 的「黑白熊猫配色白外套」换成象牙白长衫 |
  | **下摆一圈蓝色云纹** | 只做下摆带状纹样，不做满身花；这是这套衣服最标志的一笔 |
  | 红色盘扣 | 小面积高饱和红，取代 V1 的红腰带 + 中国结 |
  | 及腰长发、低束 | 取代 V1 的双环发髻 + 金发夹 |
  | 黑靴、冷感表情 | 保留；冷感与 V1 的半眯眼气质兼容 |
  | 侧开衩的轮廓感 | 保留开衩，但**只到膝且内搭深色长裤** |

  | 舍弃 | 原因 |
  |---|---|
  | 橙红发、蓝瞳、紫伞、遮阳斗篷、角色名 | 强 IP 识别元素，只参考服装结构不搬角色 |
  | 高开叉露腿、无袖、露肩 | 按《牌拳》既有口径处理成中性全覆盖战斗服 |
  | 拳套 / 护手大球 | 工程师明确「不一定要有」；且 V1 两个巨大圆球正是「积木感」的主要来源 |
  | V1 的双环发髻、金 8 字扣、中国结、环刃 | 属上一版琉音方向的配件，与新服装语言冲突，退场 |

  **手部替代方案**：软布缠手带 + 深色护腕。既保住「拳手」身份，
  又去掉巨大球体，也不会像裸手那样失去格斗读性。


三、合规边界（沿用之前琉音那轮的口径）
---------------------------------------------------------
只取「白长衫 + 下摆云纹 + 红盘扣 + 长发 + 黑靴」这套**服装结构与配色关系**，
不画橙红发、不用角色名、不复刻脸、不做伞与斗篷、不做露肤特写。
产出是《牌拳》自己的原创拳手设定图，不是任何既有角色的模型。
生成模型本身也仅作造型评审依据，未做 IP 合规审查。


四、prompt 决策（踩过的坑，别再踩）
---------------------------------------------------------
* 长度 976 字符 < 1024（上一轮 1058 被服务端拒绝）。
* **完全不出现 glove / boxing / 拳套 字样，连 "no boxing gloves" 也不写**：
  生成模型对否定词不稳定，反复前置单一属性会把语义簇推偏
  （上一轮 SDXL V5 因反复写「拳套」翻成男性中式道服，已作为负结果留存）。
  只正面写 `soft cloth hand wraps and dark wrist guards`。
* 保留 `Neutral A-pose for rigging` / `single character` / `no base` /
  `no weapon` / `no background`：与 V1 同口径，两张预览图可直接对比。
* `side slits to the knee over fitted dark indigo trousers` 明确写内搭，
  防止模型把「旗袍」默认成高开叉露腿。
