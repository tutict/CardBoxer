《牌拳》V4b 定稿造型 · 建模图展示
================================================================
日期：2026-11-07
目录：CardBoxer-bake/model-preview-v4b/


一、这轮交付什么
----------------------------------------------------------------
工程师要「看看新版本的建模图」。`3d-model-probe-v4b/` 里本来就有 7 张
同相机渲染，但分散在几十个产物文件里，而且已有的对照板是三版比大小
用的、格子太小不适合单独看新版本。所以本目录只做整理与展示，不重新
生成模型、不重渲、不改材质：

  V4b-model-preview-board.png   1800x1320，四视角 + 三特写一次看全
  V4b-model-viewer.html   完全离线的九视角切换页（←/→ 或数字键 1-9）
  v4b-*.png             7 张原尺寸渲染图，逐字节复制自 3d-model-probe-v4b/
  artifact_01.png       工程师当初选定的那张服务预览 PBR 原图
  V3-V4-V4b-three-version-comparison.png 三版演进对照

`3d-model-probe-v4b/` 原归档一行未动；游戏源码 0 文件改动。


二、渲染口径（重要）
----------------------------------------------------------------
`identify_reference.py` 已算出工程师选的是服务预览 **PBR 原图**，
不是后做的 toon 立绘。所以这批图一律是 Blender 5.2.3 的
`render_character.py` 七视角正交渲染、**保留生成模型自带的 3 张
PBR 贴图**，没有加 cel shading、没有加描边、没有调色。
展示板只把透明底合成到中灰卡片上，只为看清白色长衫，不改材质。

参数从 `render_v4b.json` / `model_inspection.json` 读，不写死：
  Blender 5.2.3 LTS，7 shots，全身 ortho 2.3 @768²、
  脸特写 ortho 0.46 @1024²、上半身 ortho 1.0 @1024²，
  全部 target_z 与角度逐项记录；归一化 scale 1.652229。


三、看图能确认什么
----------------------------------------------------------------
达成：
  * 白色长衫立领斜襟 + 红盘扣，靛蓝云纹下摆，深蓝长裤，黑厚底靴。
  * 明黄短披肩领、黑色不对称 V 形襟片 + 白色叶枝印花（叶瞬光线）。
  * 太极圆牌、金绳结、红流苏、腰包、银环耳环、青护腕 + 银环镯（仪玄线）。
  * 白色长袖到手腕，肩与上臂不再裸露（V4 的偏差已修掉）。
  * 白发箍 + 两侧红色小发夹（不再是 V4 那套贴具体角色的几何角）。
  * 脸模：琥珀金分层虹膜 + 双高光、清晰粗黑睫毛线、细眉、
    可辨鼻梁与唇形、干净肤色、刘海不遮眼。
  * 55° 侧视有真实的披肩厚度、长衫前后片、马尾层次，不是纸片。

如实说的局限：
  * 发尾仍有半透明灰色薄片 —— 开放薄壳 mesh 的老问题，四版都在。
  * 仍是 A-pose 站姿，没有出拳 / 受击 / 任何动作帧。
  * GLB：57,901 顶点 / 79,986 三角 / 3 张内嵌 PBR /
    0 skins / 0 animations / 2,035 连通壳；自动绑骨 0/57,901 覆盖。
    **换造型换不出骨架**，这批图只是造型定稿，不是能进引擎的动作资产。


四、附加：可旋转的 3D viewer
----------------------------------------------------------------
`3d-model-probe-v4b/generated_model_20261107-163949_viewer.html` 用
model-viewer 直接加载同目录 `artifact_03.glb`，可拖拽旋转 / 缩放。
它需要能访问 googleapis CDN 加载 model-viewer 脚本，且 GLB 37 MB；
内网或 file:// 下可能加载不出来 —— 这时用本目录的离线查看器看七张
渲染图即可，它不依赖任何外网与 fetch。
