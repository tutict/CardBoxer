五、删除为什么没执行 + 交给工程师的命令
----------------------------------------------------------------
实测：`net session` = ADMIN=NO；往目标目录写临时文件 = DIR_WRITE=NO。
这是 Windows ACL（标准用户 token 对 `Program Files` 无写权限），
**不是沙箱策略，关闭沙箱也提不了 UAC**。所以本会话删除必然失败，
不拿一次注定失败、还可能弹窗挂住的操作冒充「试过了」。

请以**管理员身份**打开 PowerShell，粘贴执行（路径全 ASCII，命令自带护栏）：

    $p = 'C:\Program Files\Blender Foundation\Blender 4.4'
    $files = @(Get-ChildItem -LiteralPath $p -Recurse -File -Force)
    $bad = @($files | Where-Object { $_.Extension -ne '.pyc' })
    if ($files.Count -ne 209 -or $bad.Count -ne 0) {
        throw "ABORT: files=$($files.Count) non-pyc=$($bad.Count)"
    }
    Add-Type -AssemblyName Microsoft.VisualBasic
    [Microsoft.VisualBasic.FileIO.FileSystem]::DeleteDirectory(
        $p,
        [Microsoft.VisualBasic.FileIO.UIOption]::OnlyErrorDialogs,
        [Microsoft.VisualBasic.FileIO.RecycleOption]::SendToRecycleBin
    )
    if (Test-Path -LiteralPath $p) { throw 'STILL EXISTS - not deleted' }
    "RECYCLED_OK files=$($files.Count)"

护栏说明：
* 先断言恰好 209 个文件且全是 `.pyc`，数量或类型不符立即 ABORT，
  防止这段时间里目录内容变了还照删。
* `RecycleOption.SendToRecycleBin` = 进回收站，可恢复；不做彻底删除。
* 删完 `Test-Path` 必须为 False，否则抛 `STILL EXISTS`。

执行后复核：

    Test-Path -LiteralPath 'C:\Program Files\Blender Foundation\Blender 4.4'   # 期望 False
    Test-Path -LiteralPath 'C:\Program Files\Blender Foundation\Blender 5.2'   # 期望 True
