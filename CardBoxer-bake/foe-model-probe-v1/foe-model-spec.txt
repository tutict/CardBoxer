《牌拳》对手怪造型规格 V1 · 参考绝区零「盗洞客」视觉语言
================================================================
日期：2026-11-07
需求：工程师「对手怪要做成绝区零盗洞客那种模样」


一、资料查证与来源判别（8 源）
----------------------------------------------------------------
**关键辨析：官方口径里「盗洞客」不是怪物，是群体称谓。**
  * 百度百科「盗洞客」条目 / 游戏狗《绝区零盗洞客介绍》：
    空洞调查协会把「一切官方编制之外、非法利用空洞的组织或个人」
    定义为盗洞客；不是一个组织，没有统一制服与固定造型；
    亦正亦邪、靠空洞牟利，委托绳匠带路。委托事件里还出现过
    「面色凝重的盗洞客」「被重度侵蚀的受困盗洞客」。
  * 所以「那种模样」不能直接照抄某个角色，必须落到
    **盗洞暴徒（Hollow Thug）敌人系** 的稳定视觉语言上。

采纳（官方 / 百科可交叉验证）：
  * 米哈游百科「盗洞暴徒·盗猎客」：胆小狡诈、躲暗处冷箭伤人、
    惯用复合手弩、远距离三连点射（→ 取「不正面、鬼祟、远程骚扰」气质，
    **不取武器**）。
  * 萌娘百科「蛮横力士」（中/繁两版一致）：身穿**改装后的施工辅助
    动力系统**，以**建筑废料**作一次性武器；厚重设备像合身健身装；
    萌点列出「罪犯、肌肉男、拳套、**覆面、头盔**」。
  * 米哈游百科「非法辅助单位·怒汉」：盗洞暴徒把损毁机甲按
    「**零件缝合、低价平替**」原则改装修复，会加**额外涂装**、
    甚至大功率扩音喇叭（→ 取拼装感、警示涂装、非制式）。
  * 萌娘百科「秽蚀·蛮横力士」：机械装甲几乎与血肉融为一体、
    意识溃散、仅存破坏本能（→ 取**轻度侵蚀／结晶**，做到「怪」，
    但**不取血肉融合、不取恐怖表现**）。

排除：
  * 米游社《【绝区零同人文】第四章 修整与改装》——标题即同人，
    里面的半覆盖式装甲 / 振金电刀 / 自毁按钮全是二创，整篇不采。
  * 同人文 / cos 站 / AI 标签站里的性化二创、露肤、黑丝、狐耳等，
    与官方设定和项目从 V1 起守的中性全覆盖边界都冲突。
  * GameVika / HoYoWiki 的弱点属性、失衡值等战斗数值可采，
    但与造型无关，不进 prompt。
  * 不写任何敌人专名（蛮横力士 / 山狮瑞扎 / 怒汉 / 盗猎客）、
    阵营名、IP 名、角色名 —— 只取结构语言，不复刻具体条目。

一句话：可迁移的是「**覆面 + 改装施工动力装甲 + 废料拼装 +
非制式警示涂装 + 轻度侵蚀结晶**」，不是某只怪的复制。


二、设计目标：先解决「两人一模一样」
----------------------------------------------------------------
上一轮 `portrait-integration-preview-v4b/` 如实指出：战斗区 A 图里对手只是把玩家
立绘**镜像 + 冷色**，两人同一张静态 A-pose，没有对视没有出拳。
本轮对手怪的首要判据不是「好看」，而是**剪影与明度一眼可分**：

    玩家 V4b              对手怪 V1
    纤细、修长            宽肩、厚躯、短粗四肢、微前倾
    浅色（象牙白/明黄）    深色（炭黑/铁锈红/工业橙）
    长发飘带、布质长衫    兜帽覆面、硬壳拼装、无飘带
    露脸、有表情          全面罩、单眼护目镜、无表情
    国风盘扣云纹          铆钉管线、警示条纹、以太结晶

配色只留一处电光青作小面积呼应（与玩家的青护腕同族但不抢），
其余全部压到深色，保证同屏时不会糊成一块。

**为什么仍做人形骨架**：`baked2.json` 是 11 个 2D 平面关节，
程序化 3D / 2.5D 链和后续 C 图集都按人形骨架搭。做成完全非人的
多足怪会推翻坐标桥。所以「怪」靠覆面、无表情、装甲与结晶表达，
不靠改骨骼数量。


三、造型条款（写进 prompt 的）
----------------------------------------------------------------
  1. 体块：宽肩微驼、桶状厚躯、短粗四肢、超大铆接护臂、厚底钢头靴。
  2. 头部：深色全面罩呼吸器 + 单片裂纹电光青护目镜 + 深兜帽；
     脸完全遮住、无表情、无露肤。
  3. 拼装：非制式改装施工动力框架、错配螺栓装甲板、外露铆钉与管线、
     补丁帆布、胶带缠绕、橙黄警示条纹、不对称胸甲、
     炭黑与铁锈红掉漆。
  4. 侵蚀：单肩小簇以太结晶 + 细青色裂纹 + 微弱发光，
     干净风格化，不做血肉融合。
  5. 配件：厚重工具腰带、挂包、盘绕电缆、垂挂金属牌。
  6. 手：厚实缠手带 + 铆接护臂（**不写 glove/boxing**，
     V5 踩过反复前置拳套把语义簇推到男性中式道服的坑）。
  7. 姿态与输出：中性 A-pose、单角色、头到脚、正面、
     无底座 / 无武器 / 无背景 / 无文字。


四、合规与工程边界
----------------------------------------------------------------
  * 中性、全覆盖、无性别特征、无露肤、无性化、无血腥恐怖。
  * 不出现任何 IP 名称、敌人专名、角色名、阵营名、logo / emblem。
  * 无武器（《牌拳》是卡牌比牌，武器是牌不是弩 / 废料锤）。
  * 仍走「生成模型 = 静态单 mesh」的既有口径：本轮只评造型，
    不承诺骨架、不承诺能直接进 Godot、不渲动作帧。
  * 本轮不改游戏源码、不导 Godot、不生成 .import。
