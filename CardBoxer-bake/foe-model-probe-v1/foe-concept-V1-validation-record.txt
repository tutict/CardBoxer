三、查证要点（来源判别比查资料本身值钱）
----------------------------------------------------------------
  官方口径里「盗洞客」是**非法进入空洞者的群体称谓**，不是固定怪物、
  没有统一制服。真正有稳定视觉语言的是「盗洞暴徒」敌人系：
  覆面/头盔、改装施工辅助动力系统、建筑废料拼装、零件缝合低价平替、
  非制式警示涂装、秽蚀版轻度结晶侵蚀。
  同人文（半覆盖装甲/振金电刀/自毁按钮）、cos 站与 AI 标签站的
  性化二创整篇排除；不写任何 IP 名、敌人专名、角色名、阵营名。
  设计目标定为**剪影对立**，不是「好看」：见 `foe-model-spec.txt`。
  保留人形骨架，因为 `baked2.json` 是 11 个 2D 平面关节，
  做成多足怪会推翻既有坐标桥。

六、变异验证（4/4 CAUGHT，逐字节还原）
----------------------------------------------------------------
  M1 `prompt.txt` 改一个词            → prompt_ok_and_sha_self_consistent 红
  M2 `gen_stdout.json` 429→200        → quota_429_recorded_no_fake_artifacts 红
  M3 对照板换成概念图副本             → concept_board_valid 红

  四条都带「点名一条应保持绿色的哨兵」，四组均 `restore=True`
  （sha256 逐字节比对），clean re-run 10/10 GREEN。

  **M4 首次崩掉的根因**：`concept_compare_stats.json` 是
  `json.dumps(indent=2)` 写出的，数组逐行展开且 Windows 下为 CRLF；
  M4 却用单行 `b'"player_bbox_in_source": [174, 96, 594, 672]'` 做 needle，
  实测匹配 0 次。assert 直接抛出，脚本崩在第 4 组，clean re-run 没跑，
  盘上 `verify_concept.log` 停在 M3 变异中间态（9/10 FAIL）。
  修法：换成不含换行的单行元素 needle `b"    174," → b"    1,"`，
  实测 `needle_count=1`；`CRLF=18 LF=18` 已实测，避开行尾口径。

  **加固不是顺手改的，是补一条债**：把「锚点失配」从 assert 崩掉改成
  `DID NOT RUN` 记录并计入未证明（caught 分母不减、verdict 必 FAILED），
  同时保证其余 case 照跑、clean re-run 照跑。
  `selftest_did_not_run.py` 8/8 实证这条分支有牙：故意把 M4 锚点改成
  不存在的 999，得到 `M4 DID NOT RUN` / `did_not_run=1` /
  `3/4 CAUGHT` / `MUTATION_CONCEPT_FAILED` / `clean_rerun=GREEN` /
  `restore=4/4`，M1–M3 仍逐条有结论；被测脚本按 sha256 逐字节还原
  （`restore_sha256=True`）。随后重跑真脚本把 log/result 恢复到
  4/4 + `MUTATION_CONCEPT_OK`，最终 clean verify 10/10。


七、看图结论（人的判断，不是脚本结论）
----------------------------------------------------------------
  正面全身概念图基本命中规格：宽肩厚躯、深兜帽全面罩、无露肤、
  铆钉管线补丁披风、单肩青色结晶、炭黑铁锈红 + 橙黄警示条纹、无武器。
  与玩家 V4b 并排时，剪影 / 明度 / 材质语言三项都一眼可分。

  **如实偏差**：
    * prompt 要的「单片裂纹护目镜」生成成**双圆镜片防毒面具**；
    * 风格偏写实重甲插画，比玩家 V4b 的二游 PBR 更硬，同屏时
      「一个游戏里两种渲染口径」的风险要到 3D 同相机渲染才能判；
    * 第二张 `input_fidelity=high` 视角几乎没变，是负结果；
    * 对照板右列贴片边界仍有一道极淡的竖向羽化过渡带，
      属 2D 合成痕迹，不构成此前那块内亮硬边 / 黑方块 / 水印残字。

  对照板三处缺陷全靠看图抓出：初版右列浅灰底形成嵌套矩形 +
  右下角水印；第一修 `feather=22` 过大把人物脚边吃淡并留内亮方块；
  最终水印改从左邻背景条带复制、卡片底按概念图上下背景色逐行插值、
  羽化收到 5px。**10 条脚本判据没有一条评排版。**
