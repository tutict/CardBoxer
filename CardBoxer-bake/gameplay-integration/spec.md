# 牌拳：攻防读牌与小丑构筑（已批准）

## 2026-11-21 用户试玩后的调整（以本节为准）

用户要求扩大整个页面、取消两次三张牌选择，并在开打前看清敌方招式以安排防守。

- 默认最大化窗口；战术界面使用 1600×900 逻辑画布。五拍计划、8～10 张手牌、确认按钮同页可见，复用原擂台与角色。
- 从 8 张手牌中一次按顺序选 5 张动作牌；小丑仍是六选三。无需先确认弃牌。
- 每轮进入编排前，敌人先换牌并锁定五张有序计划。随机遮住其中恰好两张，其余三张显示实际牌名、起手和伤害。暗牌在玩家确认开打时揭开。
- 敌方牌序、遮掩位置与明牌不随玩家编排、撤销或换牌变化。AI 不读取玩家手牌或尚未提交的计划。
- 玩家可在同一页直接点击手牌上的“换”，每轮最多换三次；Shift+数字提供等价操作。换掉已编排的牌时只撤销该位置，其余顺序保留。
- 五张一起计算最强牌型，牌序只影响攻防结算。牌型依次为散牌、一对、两对、三连、三同、五连、葫芦、四同、五同。三连可由五张中的连续三点组成；五连需五点连续。顺势支持三连/五连，三重奏支持含三同的高级牌型。
- 五牌型平加/倍率：散牌 0/1，一对 1/1，两对 2/1.10，三连 2/1.15，三同 3/1.25，五连 4/1.30，葫芦 4/1.35，四同 5/1.45，五同 6/1.60。攻防仍主导是否命中。
- 将特殊牌效、伤害加乘和小丑触发写入动作/小丑定义，通用效果执行器负责执行；计划长度由规则配置提供，避免结算、AI 和 HUD 写死三拍。

工程选择：保留原生 Godot 和既有资产；扩大界面画布，同时按比例呈现既有擂台。效果采用现有 GDScript 字典目录与通用事件处理，方便增加牌种和被动。

以下为已实现并验证的三拍首版记录；与本节冲突的条目已被上述用户修改覆盖。


## 2026-11-21 HUD 精简调整

用户反馈上方编排栏占屏过大、手牌和计划区重复说明过多，并补充牌面应使用克制颜色，避免影响字字清晰度。

- 两行五拍改成压缩的横向卡槽，取消独立距离块，距离并入玩家行标题。隐藏牌以低亮度暗纹和问号标识，不另加重复的“隐藏”说明。
- 手牌保留牌点、类别小标、招式名与一条关键数值。完整效果说明通过悬停查看；不再在牌面重复按键序号、类型标题和说明段落。
- 整体使用低饱和动作分类色与深色底，文字保持亮色高对比。Comfy 生成的圆环纹样只用作敌方暗牌的低亮度背景。

用户选择：回合制读牌；扩大手牌及动作牌种类；参考《小丑牌》的牌型、常驻被动及连锁；攻防主导；只公开首招类别；开局随机六选三；沿用三局两胜。

## 首版规则

- 8 张手牌，最多换 3 张，有序出 3 张；18 种动作牌各两份，有限牌组和弃牌堆循环。起手至少两攻一防。额外摸牌仅令下一轮扩手，最多 10 张。
- 每局 100 HP、最多 6 轮；先获两胜提前结束，整场最多三局，局平不计胜，满三局胜局相同为场平。小丑及怒火跨局保留，其余牌组、距离、战斗状态每局重置。
- 三张牌分别同时交锋。依起手时间完成动作，同时间先建立防御/位移再同时扣血。攻击打断只取消当前拍。打康伤害 x1.25；同速交换伤害；霸体不免伤、不被普通抢招中断，投技可以中断。
- 成功侧闪/招架或攻击打空产生对手下一拍破绽，确反优先且 +3；第三拍破绽可延续到下一轮首拍。确反与打康互斥。卸力在起拍清除自身破绽，完成起手后下轮多摸一张。
- 距离为贴身/中距/远距，开局中距；普通近身打前两档，投技打贴身，气功波打任意档。突进/后撤改变一档。
- 格挡减伤80%，投技和破防击绕过格挡。侧闪躲普通攻击；招架克制普通近身；延迟重击克制闪避/招架。蓄势令下一次攻击尝试加伤3。
- 新牌（rank/windup/damage/clip）：佯攻1/4/0/jab，骗格挡/侧闪/招架；招架2/2/0/guard；延迟重拳3/12/9/cross；破防击4/9/8/cross；霸体重拳6/10/10/uppercut；追击拳7/6/5/jab，上一拍近身命中或对手破绽时加伤3并接近一档。
- 散牌(+0,x1)、对子(+1,x1)、三连(+2,x1.15)、三同(+3,x1.25)。伤害计算顺序：招式/攻防平加、牌型/打康倍率、小丑槽逐项加乘、格挡、最终一次取整。战术模式不使用实时气耗或1.9秒搓牌连招/大招。
- 怒火沿用受伤x5、上限100，满槽下轮消耗：本轮牌型平加+1、倍率+0.1。

## 小丑

八选六，六选三，不重复；选择顺序即触发顺序。AI拥有同样的构筑规则，其装备公开。

| id | 名称 | 效果 |
|---|---|---|
| shadow | 掠影 | 闪避成功后下一次攻击尝试+3 |
| opening | 趁隙 | 确反伤害x1.25 |
| counter | 抢拍 | 打康伤害+3 |
| pressure | 压制 | 本轮首次打康令下一拍攻击起手-2，最低1 |
| wind | 追风 | 本轮首次闪避/招架令下轮多摸1 |
| sequence | 顺势 | 三连本轮攻击伤害x1.25 |
| triple | 三重奏 | 三同本轮攻击伤害+2 |
| breaker | 破阵 | 本轮首次投技/破防命中令下轮多摸1 |

被挡/打空不产生普通命中类连锁。同一事件同一小丑只触发一次；日志解释伤害加值、乘数及资源触发。

## 工程与验证

新增默认 tactical 模式，保留 taikou/realtime。纯接口 resolve_exchange(player_plan, enemy_plan, context) -> {events,next_state}。AI只用自己的牌和公开状态/历史，先锁定牌序再显示首招类别；弃牌不超三张。

流程：选小丑、换牌、选有序三牌、亮牌、三拍队列、补牌。规则不依赖渲染帧率；接触事件只扣血一次；暂停、重开、KO不会重放旧伤害。新牌复用既有2D/3D骨骼动作。HUD显示8~10手牌、三牌序、小丑、距离、公开提示；1~9/0选牌，退格撤销，空格确认，P暂停，R重开，鼠标等效操作。

验证：弱牌型读招获胜、打康/确反/同速/防御/距离/霸体、跨轮状态、被动顺序和一次触发、牌组守恒与种子复现、AI不读隐藏输入、完整六轮三局收场、30/60/120FPS及暂停重开、原两模式回归、2D/3D实际交互。
