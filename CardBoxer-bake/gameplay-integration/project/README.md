# 牌拳 / CARD BOXER

默认是回合制卡牌格斗：**牌序决定攻防，牌型和战术小丑放大收益。** 从8张手牌一次编排5张动作，提前读敌方三张明牌，用闪避确反、抢起手打康、投技和佯攻破解防守。敌人五张牌先锁定，再随机遮住两张。

## 启动与操作

- `play.bat`：新战术模式、原生3D角色。
- `play-2d.bat`：相同战术玩法、2D角色。
- `play-classic.bat`：原太阁式三张比牌。
- `play-realtime.bat`：原实时卡牌格斗。

Godot 4.5 / GL Compatibility，也可直接打开 `project.godot`。启动默认最大化；战术界面使用1600×900画布，按窗口等比缩放。`CARD_BOXER_BATTLE_MODE=tactical|taikou|realtime` 选模式，`CARD_BOXER_3D=1` 开3D。

| 操作 | 作用 |
|---|---|
| 鼠标点击 / `1–9` | 选手牌；开局 `1–6` 选小丑 |
| `0` | 第十张手牌 |
| `Backspace` | 撤销最后一张 |
| 手牌“换”按钮 / Shift+数字 | 可选换一张，每轮最多三次 |
| 点击已编排的牌槽 | 撤回该张，其余顺序保留 |
| 空格 / Enter / 确认按钮 | 装备小丑或确认五张开打 |
| `P` / 暂停按钮 | 暂停、继续 |
| `R` / 重开按钮 | 重新构筑一场 |
| 悬停手牌、明牌或小丑 / 数字键选牌 | 查看完整说明；暗牌不泄露招式 |
| `Tab` | 原有角色档案 |

## 一场怎样打

1. 从随机六张小丑里选三张，选择次序就是触发次序。再次点击取消，退格撤销末选。
2. 每轮直接进入编排页。对手已锁定五招，显示三张实际牌名、起手和伤害，随机两张为暗牌。编排或换牌不会重抽对手的牌和暗牌位置。
3. 从8张手牌按顺序选5张，空格开打并揭开暗牌，双方逐拍交锋。换牌是同页可选操作；换掉已编排的手牌只撤回该张。
4. 抢中攻击起手是打康，伤害×1.25并取消该拍攻击；有效闪避、招架或打空制造下一拍破绽，确反优先且加伤3。
5. 出过的牌进入弃牌堆，轮末补手牌。小丑可令下一轮多摸，最多10张；牌堆耗尽后洗回弃牌。

三局两胜，整场最多三局；每局100HP、最多六轮，未KO时比剩余HP。平血或双KO记局平，三局后胜局相同记场平。小丑和怒火跨局保留。

## 攻防与构筑

贴身、中距、远距是三档距离。突进接近、后撤拉开；投技只打贴身，普通近身打贴身和中距，气功波打所有距离。

格挡减伤80%，投技与破防击绕过格挡。侧闪躲普通攻击；招架化解普通近身攻击。延迟重拳抓闪避与招架；霸体抗普通抢招打断但照常承伤，投技可以打断霸体。蓄势强化下次攻击，卸力清除起拍破绽并奖励下轮摸牌。

五张牌计算最强牌型，排序不影响牌型，出招顺序影响攻防。三連可来自其中连续三点，五连必须五点连续。牌型不直接判胜：

| 牌型 | 平加 | 倍率 |
|---|---:|---:|
| 散牌 | 0 | ×1 |
| 一对 | 1 | ×1 |
| 两对 | 2 | ×1.10 |
| 三连 | 2 | ×1.15 |
| 三同 | 3 | ×1.25 |
| 五连 | 4 | ×1.30 |
| 葫芦 | 4 | ×1.35 |
| 四同 | 5 | ×1.45 |
| 五同 | 6 | ×1.60 |

伤害依次计算基础及攻防加值、牌型及打康倍率、小丑从左到右、格挡，最后统一取整。怒火满100后，下轮EX额外牌型平加1、倍率增加0.1。

18种动作：刺拳、交叉反击、上勾拳、扫腿、气功波、投技、突进、后撤、格挡、侧闪、蓄势、卸力，以及佯攻、招架、延迟重拳、破防击、霸体重拳、追击拳。

| 小丑 | 效果 |
|---|---|
| 掠影 | 闪避后下次攻击尝试+3 |
| 趁隙 | 确反伤害×1.25 |
| 抢拍 | 打康额外+3 |
| 压制 | 本轮首次打康使下一拍攻击起手-2 |
| 追风 | 本轮首次闪避/招架，下轮多摸1 |
| 顺势 | 三连或五连攻击伤害×1.25 |
| 三重奏 | 三同、葫芦、四同或五同攻击伤害+2 |
| 破阵 | 本轮首次投技/破防命中，下轮多摸1 |

例如 `侧闪 → 刺拳 → 后撤 → 格挡 → 蓄势` 配 `掠影 → 趁隙 → 追风`：闪过来招后，刺拳确反；五张中的点数1、2、3构成三连，最终伤害为(4+2+3)×1.15，再掠影+3、趁隙×1.25，取整17。追风令下轮手牌变成9张。触发的小丑高亮，结算显示加值与倍率来源。

## 验证与开发

`python tools/verify_tactical.py --godot <Godot控制台exe>` 运行战术与原模式回归，日志和JSON汇总默认存到上级 `logs/full-suite`。单项示例：

```text
godot --headless --path . --script res://tests/tactical_rules_check.gd
godot --headless --path . --script res://tests/tactical_match_check.gd
godot --headless --path . --script res://tests/tactical_planning_check.gd
godot --headless --path . --script res://tests/tactical_integration_check.gd
godot --headless --path . --script res://tests/tactical_ui_check.gd
```

`CARD_BOXER_SEED=2026` 固定牌组和决策种子；`CARD_BOXER_TACTICAL_BOT=1` 自动跑完整比赛。`tests/tactical_capture.gd` 配 `CARD_BOXER_TACTICAL_CAPTURE=<输出目录>` 生成GPU渲染的界面和确定性攻防截图。

战术模块分为定义、效果执行、纯规则、有限牌组/比赛控制、只读AI、演出和HUD。角色及气功波弹道不运行实时命中；伤害由接触事件只应用一次。现有角色、贴图、原生骨骼动作全部复用。

扩展动作与小丑时，在 `tactical_defs.gd` 的目录中定义元数据、`on_start`/`on_ready`、`damage_effects` 或小丑事件。`tactical_effects.gd` 统一处理状态加值、距离、条件伤害与每轮一次触发；结算不按卡牌ID分支。`PLAY` 控制默认计划长度，小丑槽和暗牌数分别配置；AI使用每类起手的有界候选搜索。
