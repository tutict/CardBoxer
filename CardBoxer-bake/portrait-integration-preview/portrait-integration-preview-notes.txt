一、这是什么 / 不是什么
------------------------
这是 Pillow 离线合成的效果预览，不是 Godot 引擎实渲。
底图是真实引擎截帧 `background-candidates/rage-meter/rage-meter-full-meter.png`（1280x720），
立绘来自 `3d-model-probe-v3/zzz-{front,angle25,angle55,back35}.png`（768² 透明）。
A/B 两张贴进真实截帧的图都打了「离线合成 · 非引擎实渲」标记。

本轮游戏源码零改动：没有改 arena.gd / hud.gd / fighter.gd / fighter_skin.gd，
没有新资源进 Godot，没有生成 .import，没有跑引擎内截帧，没有渲任何动画帧。

四、看图结论（不粉饰）
----------------------
A：明显比火柴人好看，白长衫 / 红盘扣 / 云纹在紫调擂台里能共存，脚底与原有阴影对齐，
   没有残留剪影、没有矩形硬边。但两人是同一张静态正面 A-pose（对手只是镜像+冷色），
   没有对视、没有出拳、没有动作帧；240px 不能照抄进引擎，真接要按 11 关节坐标桥重算。

B：148x150 里半身像成立，名字条清晰；40px 圆头像仍看得出黑色发型与红盘扣。
   但同一屏里「精致二游脸」和「橙色圆头火柴人」并列，风格冲突非常刺眼 ——
   这张图本身就是「不要只换 UI 不换角色」的证据。

C/D：静态 UI 位是这套立绘当前最合适的落地点，因为不需要动作帧。
   C 的三个视角能看清斜跨胸带、腰包、下摆云纹、背面 35° 的腰包位置；
   D 的读数：40px 可辨发型与盘扣，64px 起五官可读，96px 起服装纹理成立；
   小卡一律用半身像，不用全身。

一句话结论：造型这一半成立了，可用的是「静态位」；战斗区替换必须等动作帧。
