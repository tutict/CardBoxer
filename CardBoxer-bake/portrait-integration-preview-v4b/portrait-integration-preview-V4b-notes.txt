----------------------------------------------------------------

三、看图抓到并修掉的三处缺陷
----------------------------------------------------------------
1. 斜向装饰被复制：初版沿用 V3 的水平平移填充（dx=±190，从擦除框外侧
   取背景），差异图与 `debug-A-left-character.png` 显示左上角的白色斜线被复制进
   两个人物两侧，看着像背后插着两根棍子。
   改成两块擦除框**共用两人之间 x=560..760 的纯背景**：同 y 带，绳索
   水平对齐，既没有人物也没有那条斜线。判据 `erase_fill_uses_clean_center_patch`
   用正则从脚本里提 (box, dx) 重算源区间，可复算、不写死数字。
2. 擦除框太窄：由 120px 放宽到 200px（330..530 / 750..950），
   盖住 240px 高时约 175px 宽的 V4b 立绘。
3. 尺寸样张混进角度变量：换 1024² 脸特写母图后，64px 那枚用 25° 侧脸
   会偏出圆心。三枚头像统一改正面脸，只变尺寸（控制变量）。

复核：A 图人物完整、脚底落在地面阴影、绳索水平连续、框外 0 改动；
B 图卡 1/5 半身像不溢出、名字条无叠字、中间三张卡逐像素原样；
C 板信息表四行完整；D 板三枚头像无黑方块、标题互不重叠。

五、必须如实说的局限（脚本全绿不等于能用）
----------------------------------------------------------------
* **B 图风格冲突更刺眼了**：精致二游半身像 / 脸特写头像，与战斗区
  橙色圆头火柴人同屏。这张图本身就是「别只换 UI 不换角色」的证据。
* **A 图两人是同一张静态 A-pose**：对手只是镜像 + 冷色，没有对视、
  没有出拳、没有动作帧。V4b 仍是 0 skins / 0 animations / 2,035 连通壳
  的静态单 mesh，自动绑骨 0/57,901 覆盖 —— 换造型换不出骨架。
* **小卡看不出脸模优化**：148x150 卡里脸只有约 20px，本轮优化的
  琥珀分层虹膜 / 睫毛 / 细眉主要在 96px 以上头像和 `v4b-upper.png`
  特写里才读得出来。
* 未导 Godot、未生成 .import、未渲 2~8 帧刚性绑定小样本、未渲 228 帧
  全量图集、未做 IP 合规审查。`boxer_3d.py` / `fighter.gd` /
  `fighter_skin.gd` 一行未动。
