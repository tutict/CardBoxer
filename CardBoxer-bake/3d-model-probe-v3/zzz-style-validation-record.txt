  | 非对称 | 基本对称 | **单侧长马尾 + 碎刘海 + 不对称下摆** |
  | 脸 | 半眯眼、偏写实 | 大眼、层次瞳孔、更「二次元」 |
  | 鞋 | 素黑短靴 | 系带厚底靴 + 青色鞋底 |

  | 国风基底 | 白长衫 + 红盘扣 + 蓝云纹 | **原样保留** |
  | 渲染 | PBR 柔光、无描边、白底 | **cel-shading 节点链 + 同色相细描边 + 低饱和深底 + 地面投影** |

`three-model-versions-comparison.png` 三张并排，第三张明显最接近「bold cel-shaded urban anime」。
**但没到绝区零官方立绘的水准**：硬边三分明暗几乎看不见，只做到「平涂 + 描边 +

另一半老问题**一点没变**：仍 0 骨架 / 0 动画 / 1,557 个开放壳 / 自动绑骨 0 覆盖。


二、风格查证：把「绝区零风」拆成两层
---------------------------------------------------------
依据（详见 `zzz-style-spec.txt` 第一节）：
  - 微信公众号《拆解〈绝区零〉视觉辞典》：复古都市 / 街头潮流 / 美式卡通；
    互补色与分裂补色；色块体积不大；阵营化机能风与不对称装饰。
  - 微信公众号《二次元复古街头风？》：**「取用相同色相但明度更低的颜色的
    细线条作为人物描边」**，与《原神》全黑描边对比；低饱和高级灰基底 +
    少量醒目亮色，明度对比更强烈。
  - 凤凰网 / GameRes：**叶瞬光以国风武侠为根基，融合传统美学与现代都市
    气质**；2.0 卫非地粤式茶楼 + 港风街巷。
  - 搜搜游戏网：风格化写实主义，比例适度拉长却不失人体力学逻辑；面部大胆
    简化、瞳孔多层同心圆高光、皮肤不用 SSS、手绘感色块过渡。
  - ColorCove / PixelsInOrbit：**bold flat colors and sharp shadows rather than
    soft gradients**。
  - TrueSight 水熊主美分析：机能风 = 外露金属连接件、非对称衣物解构、战术
    背带、用视觉复杂度拉开与传统二次元的距离。

  | 层 | 特征 | 落地手段 |
  |---|---|---|
  | **造型层** | 战术胸带/小包/腰带/扣件/拉链、护腕分层 | 3D 生成 prompt |
  | 造型层 | 非对称解构、单侧长发、层次碎刘海 | 3D 生成 prompt |
  | 造型层 | 大面积低饱和白+深靛蓝，**单一电光青**小面积点缀 | 3D 生成 prompt |
  | 造型层 | 四肢略夸张、轮廓锐利，不 Q 版、不破人体力学 | 3D 生成 prompt |
  | **渲染层** | 平涂色块 + 硬边阴影 | Blender `Diffuse→ShaderToRGB→ColorRamp(CONSTANT 三档)` |
  | 渲染层 | 同色相低明度细描边（非纯黑） | Pillow alpha 边缘 + 暗版局部色 |
  | 渲染层 | 低饱和背景 + 强明度对比 | 后处理渐变背景 + 地面软投影 |

**关键判断**：3D 生成服务只出 PBR 贴图，**不会替你做卡通渲染**。所以只改
prompt 重出模型，出来仍是柔和半写实（V3 服务预览图就是证据）。这一半必须
在 Blender 里补。

**口径冲突已辨析**：有资料说「美漫高饱和霓虹」，也有说「低饱和高级灰」。
实为场景/UI 低饱和、角色与特效小面积高饱和。本轮取「低饱和基底 + 单一
电光青点缀」，不做整身荧光。

**为什么国风 × 绝区零不冲突**：ZZZ 内部本来就有云岿山 / 叶瞬光这条
「国风基底 + 都市气质」的线。工程师上一轮的服装要求不撤销，本轮是**叠加
风格层**。（另注：V1 的琉音方向本就取自 ZZZ 2.4，等于回到这条线上。）

五、渲染侧（V3 新增，V1/V2 都没做）
---------------------------------------------------------
5.1 **探针先行** `probe_zzz_shader.py`：拿 V2 的 GLB 先验证
    `Image(baseColor) × [Diffuse→ShaderToRGB→ColorRamp(CONSTANT)]→Emission`
    这条「贴图保留型」节点链在 Blender 5.2.3 能否编译。
    结果 `TOON_TEX_PROBE_OK`：`ShaderNodeShaderToRGB` / `ShaderNodeMixRGB`
    都可用，baseColor 图 `texture_pbr_20250901` 找到，13,534 不透明像素 /
    59 个量化色 —— **云纹、盘扣、五官没被纯色 toon 洗掉**。

5.2 `render_zzz.py`：归一化 scale 1.547429 到 1.72 m；世界强度 0.75、
    SUN 2.6；三档色 `(0.52,0.58,0.70)` 冷灰影 / `(0.80,0.83,0.90)` 中间 /
    `(1,1,1)` 亮部（**不压死黑**，对应资料「no crushed blacks」）；
    正交相机 `ortho_scale=2.30`、768²、透明底，正面/25°/55°/−35° 四视角。
    `RENDER_ZZZ_OK shots=4 elapsed=1.58s`。

5.3 `make_zzz_portrait.py`（项目 venv / Pillow 12）：
    外轮廓 2px + 内轮廓 1px，颜色取**邻近角色像素的同色相暗版**
    （`MaxFilter(5)` 膨胀 premultiplied RGB → 亮度 0.30 → 降饱和 0.75），
    不是纯黑粗描边；低饱和深灰蓝竖向渐变背景 + 脚底高斯软投影。
    四张立绘 + `ZZZ-four-views.png` + `portrait_stats.json`。

5.4 判据卫生：`portrait_stats.json` 只记录 alpha bbox / 不透明像素 /
    内外边缘像素数，**不宣称「证明好看」**。四视角 bbox 都在
    x≈263~522 / y=96~672，无空帧、无裁切。


六、看图结论（不粉饰）
---------------------------------------------------------
改对的：斜跨战术胸带 + 银扣环 + 腰包把「机能层」立起来了；电光青只落在
护腕、靴沿、耳饰、发夹，体积很小、跳得出来；单侧长马尾 + 碎刘海形成
非对称；大眼与层次瞳孔明显更二次元；白长衫/红盘扣/蓝云纹完整保留；
四视角都无悬浮部件、无破面，−35° 能看到背后腰包；深底 + 地面投影让
白衫形成强明度对比；加强内外描边后轮廓线读得出来，没有脏斑点或断线。

没做到的：
  1. **硬边三分明暗几乎看不见** —— 白衫基本是一个值。第七节有实测根因。
  2. 描边在深色部件（黑发、靴、腰带）上仍偏弱，只在白衫边缘清楚。
  3. 仍是 A-pose，不是格斗站架；四视角是「转相机」不是「摆姿势」。
  4. 服务预览图本身仍是 PBR 柔光，ZZZ 味全靠后处理补，模型自身不带 NPR。
  5. 没做 UI/涂鸦/冲击帧等 ZZZ 影像语言（会引入 IP 元素，按边界不做）。


七、诊断：过曝假设被实测推翻（本轮最值钱的一课）
---------------------------------------------------------
第一眼看到「白衫一片平」时，我准备按老经验降光强（V1 2.5D 踩过
「world/SUN 过曝把 Principled 洗白」）。**没有直接调参数**，先写
`diag_toon.py` 量亮度直方图：

    zzz-front.png: opaque=75,075
    luminance_hist_8x32 = [26061, 6475, 5068, 2912, 5677, 28882, 0, 0]
    pct_above_224 = 0.0        ← 完全没有过曝像素
    coat_mean = 128.51          ← 白衫样本均值 128.5，不是 240+
    diagnosis = BANDS_SHOULD_BE_VISIBLE

结论：**三档其实存在**（暗档 26,061 px / 亮档 28,882 px），但**这套
1,557 个开放薄壳法线变化太小，同一片平面几乎全落同一档，阶梯有而边界
不在视觉显著处**。继续降 SUN / 挪 ramp 阈值就是瞎猜，遂停止调参，
改为加强内外描边（这一项看图证实有效）。

**上限要如实说**：真要达到官方立绘那种「手绘阴影块」，需要阴影贴图 /
顶点色 / 法线编辑，属于美术工作量，不是渲染脚本能补的。ZZZ 角色阴影
本来也主要是画上去的，不是靠光照算出来的。


八、绑骨复核（Blender 5.2.3，probe_rigfit_v3.py，2.34s）
---------------------------------------------------------
不是推断，是新模型重跑：`ARMATURE_AUTO` 报
`Bone Heat Weighting: failed to find solution for one or more bones`，
**0 / 55,622 覆盖**。归一化 bbox x±0.3527 / y±0.2384 / z[0,1.72]；
`f_hand` 距最近顶点 0.3161 m、`b_foot` 0.1585 m 落在几何外，
A-pose vs 格斗站架的姿势差仍在。三版实测一致：
V1 0/51,587、V2 0/51,690、V3 0/55,622。
