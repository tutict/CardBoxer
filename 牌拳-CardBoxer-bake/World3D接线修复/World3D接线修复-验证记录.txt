0. 结论先行
====================================================================

用户反馈的「两个人物重叠在一起」，真因不是 GLB 资产叠层，而是
fighter_3d_layer.gd::setup() 里两个 SubViewport 没设 own_world_3d，
共用父 World3D ⇒ 每个视口的相机都把 player + foe 两个角色一起画进去。

修复只需一行：

    sv.own_world_3d = true

放于 sv.disable_3d = false 之后、add_child(sv) 之前。
不需要显式 World3D.new()：四组独立进程实测三种写法渲出的两层
SubViewport PNG 逐字节相同，且运行时替换 world 会触发
`ERROR: Parameter "scenario" is null.`（both 组 2 条，own 组 0 条）。

决定性证据：源码落地后的真实游戏态（探针零运行时改动），两层
SubViewport 原图与 B 路线 P0「一次只挂一层」的单层真值 PNG
**逐字节相同**（player 946c0682… / foe 4e1dd508…）。
重叠不是减轻，是彻底消失。

朝向修复（yaw -55 / +55 面对面）、I 路线 foe 视觉区分、双轨默认关
全部保持。

3. 判据口径订正（四次，都有落盘证据）
====================================================================

① `own_world3d_distinct` 用 sv.world_3d 的 instance_id 判独立 → 红。
   订正：Godot 4.5 里 own_world_3d=true 时引擎内部用自己的 world，
   但 `world_3d` 这个「显式覆盖」属性 getter 仍返回 null(0)；只有显式
   World3D.new() 才让它非 0。判「生效」必须看可观察行为：
   own flag + 像素隔离 + 与 both 组 PNG 逐字节相同。

② 落地后重跑出现 3 条红，都在「own 与运行时替换等价」组。
   订正：不是回归，是等价前提变了；改为按源码是否落地的 premise
   分组，不适用的点名 N/A。同时给探针 none 组加显式
   `own_world_3d=false`，保证源码落地后仍能复算共享态对照。

③ 跨轮次 sha 不一致曾被我当成回归。实测落地后 own 组变成
   13,902 / 725，恰好等于 P0 单层真值；落地前 13,197 / 937 是
   「运行时切 world」的过渡态。订正 check_prepost.py 的判据为
   「落地后必须与单层真值逐字节相同」，6/6 PREPOST_OK。

④ 变异 M1 把 `= true` 改成 `= false` 时，守卫在
   setup.index("sv.own_world_3d = true") 抛 ValueError 崩栈，
   没有 FAIL 行 → 判 MISSED。按「异常不算证明」纪律修守卫：
   先判存在再取 index，改为优雅报红。修复后 M1 报 8 条红。

5. Creative Review 与亮度归因
====================================================================

三张板：boards/World3D修复-改前改后对照.png（标签条在帧外，不遮 HUD）、
World3D修复-角色亮度对照.png（2x2 ROI 放大）、
World3D修复-对手变暗归因.png（三格 foe ROI）。

看图：改前玩家是「重甲 + 白长衫 + 青冠 + 披风」糊成一团，改后是
干净白长衫少女；改前对手身上挂着玩家的白布下摆（串扰的直接视觉证据），
改后消失，只剩暗色重甲怪；两人面对面。

P0 遗留观测点「独立 World3D 后各层只剩自己的 4 盏灯，亮度会变化」
——量化后被证伪：

| foe ROI 平均亮度 | 值 |
|---|---|
| 改前 · 共享 World3D | 26.911 |
| 改后 · 独立 World3D | 24.826 |
| 改后 · 独立 + 关 tint | 28.470 |

shipped 与 no_tint 同为独立 World3D（4 盏灯），只差 I 路线 2D
调暗 shader；关掉 tint 净 +3.644，且高于改前。所以「灯少导致变暗」
不成立。改后 foe 偏暗的主因是 I 路线刻意调暗（vec3(0.42,0.30,0.28)）
叠加深色重甲，属既有设计。

角色像素（亮度>48）平均亮度反而略升：玩家 81.804 → 86.147、
对手 73.072 → 72.693。整块 ROI 均值下降主要来自串扰的白布消失、
留白变成暗背景。
