《牌拳》角色造型 V3 · 绝区零风格规格
==============================================================
日期：2026-11-07
需求：工程师「风格要米哈游绝区零的那种二次元风格」
性质：**风格语言提取**，不是角色/商标/UI 复刻。产物为静态 3D 模型 +
      Blender cel-shading 立绘，不改游戏源码、不导入 Godot。


一、资料核对（2026-11-07 查，多源）
---------------------------------------------------------
主要依据：
  - 微信公众号《拆解〈绝区零〉视觉辞典》（复古都市 / 街头潮流 / 美式卡通、
    互补色与分裂补色、色块体积不大、阵营化的机能风与不对称装饰）
  - 微信公众号《二次元复古街头风？》（**关键**：「取用相同色相但明度更低的
    颜色的细线条作为人物描边」，与《原神》全黑描边对比；低饱和高级灰基底
    + 少量醒目亮色、明度对比更强烈；宽松外套/马甲 + 街头潮流）
  - 凤凰网 / GameRes 转载（官方「风格即个性，差异即魅力」；**叶瞬光以国风
    武侠为根基，融合传统美学与现代都市气质**；2.0 卫非地粤式茶楼+港风街巷）
  - 搜搜游戏网（「风格化写实主义」：比例适度拉长却不失人体力学逻辑；面部
    大胆简化，瞳孔多层同心圆高光，皮肤不用次表面散射，手绘感色块过渡）
  - ColorCove / PixelsInOrbit（**bold flat colors and sharp shadows rather than
    soft gradients**；cel-shaded 3D anime、streetwear、neon accents）
  - 什么值得买 / 斗鱼资料（与原神差异：更都市、更街头、线条更锐利、造型更
    夸张、二次元属性优先、16+ 自由度更高）
  - TrueSight 水熊主美分析（机能风=外露金属连接件、非对称衣物解构、战术
    背带、通过视觉复杂度拉开与传统二次元的距离）

**一处口径冲突，已辨析**：有资料把绝区零说成「美漫画风 / 高饱和霓虹紫+
荧光粉+电光蓝」，也有资料说「低饱和高级灰为主、亮色只占小体积」。二者其实
不矛盾：**场景/UI 是低饱和灰基底，角色与战斗特效是小面积高饱和撞色**。
所以本轮取「大面积低饱和黑白灰 + 单一高饱和强调色小面积点缀」，
不做整身荧光。


二、把「绝区零风」拆成两层（这是本轮最关键的判断）
---------------------------------------------------------
  | 层 | 可迁移特征 | 靠什么落地 |
  |---|---|---|
  | **造型层** | 街头机能：战术胸带/小方包、细机能腰带+登山扣、金属扣件与拉链头、护腕分层 | 3D 生成 prompt |
  | 造型层 | 非对称解构：不对称下摆、单侧长发束、层次碎刘海 | 3D 生成 prompt |
  | 造型层 | 高配件密度：多个小挂件/发夹/扣件，但每个体积都小 | 3D 生成 prompt |
  | 造型层 | 大面积低饱和白/深靛蓝 + **单一电光青**小面积强调 | 3D 生成 prompt |
  | 造型层 | 比例略夸张、四肢稍长、轮廓锐利折线，但不 Q 版、不破坏人体力学 | 3D 生成 prompt |
  | **渲染层** | cel shading：**平涂色块 + 硬边阴影**，不要柔和渐变 | Blender `ShaderToRGB → ColorRamp(CONSTANT) → Emission` |
  | 渲染层 | **同色相、更低明度的细描边**，不是纯黑粗描边 | Pillow 后处理边缘线 |
  | 渲染层 | 面部简化、瞳孔多层高光（模型侧靠贴图，渲染侧不做 SSS） | 保留 baseColor 贴图 |
  | 渲染层 | 低饱和背景 + 少量高饱和点缀、强明度对比 | 后处理背景与地面投影 |

**边界要如实说**：3D 生成服务只产出 PBR 模型（baseColor/metallic/roughness/
normal），它**不会**替你做卡通渲染。所以「绝区零味」有一半必须靠渲染侧补；
只改 prompt 重出模型，出来的仍是柔和 PBR 半写实，看着还是不像。

四、为什么「神乐服装 × 绝区零风」不冲突
---------------------------------------------------------
ZZZ 内部本来就有这条线：官方 2.0「卫非地」把粤式茶楼、港风街巷与现代都市
融合；角色**叶瞬光以国风武侠为根基，融合传统美学与现代都市气质**；「云岿山」
阵营也是国风基底。所以「白色云纹长衫 + 机能胸带 + 电光青点缀」不是硬凑，
是同一套设计逻辑：**传统服装轮廓做基底，都市机能做叠层，小面积荧光做识别**。
工程师上一轮的服装要求不撤销，本轮是**叠加风格层**，不是推倒重来。

（另注：V1 的「琉音」方向本来就取自 ZZZ 2.4 角色，本轮等于回到这条线上。）


五、合规边界
---------------------------------------------------------
只取风格语言（cel shading、机能叠层、非对称、配色结构、描边方式），
不搬任何具体角色、阵营徽记、邦布、Logo、UI、涂鸦图案、游戏名称。
产物是《牌拳》自己的原创拳手；生成模型与渲染图仅作造型评审依据，
未做 IP 合规审查。


六、prompt 决策
---------------------------------------------------------
* ≤1024 字符（V1 踩过 1058 被拒）。
* 仍**完全不出现 glove / boxing**，手部只正面写 `dark forearm guards and
  cloth wrist wraps`（延续 V2，工程师「不一定要有拳套」不撤销）。
* 保留 `Neutral A-pose for rigging` / `no base` / `no weapon` / `no background`，
  与 V1/V2 同口径，三版预览可直接对比。
* 属性按「造型层 5~6 条」写，不堆十几个配件词——上一轮 SDXL V5 反复前置
  单一属性把语义簇推偏，这条教训继续生效。
* `side slits to the knee over dark indigo trousers` 明确写内搭，防高开叉露肤。
* 最终 1016 字符，sha256 `99e1615ac36ebaf84c4eda8c9dffdc96579dabfc0099bf2d8a4c8d97629d731d`；
  三稿从 1199 → 1077 → 1016 逐次压缩，压缩时优先砍修饰词、不砍「造型层」条目。


七、渲染侧方案（V3 新增，V1/V2 都没做）
---------------------------------------------------------
1. Blender 5.2.3 导入 GLB，**保留 baseColor 贴图**（否则云纹/盘扣/五官全丢），
   节点：`Image Texture(baseColor) × [Diffuse → ShaderToRGB → ColorRamp(CONSTANT
   三档)] → Emission`。这样既有硬边明暗，又保住 4096² 贴图细节。
2. 正交相机，正面 / 3/4 / 侧面多角度，透明背景输出。
3. Pillow 后处理：由 alpha 提边缘，画**同色相低明度的细线**描边（不用纯黑）；
   合成低饱和灰蓝背景 + 简化地面投影。
4. 判据：不看脚本「全绿」，看图确认是否真的有「平涂色块 + 硬边阴影 +
   细描边 + 小面积荧光」。脚本只证明贴图没丢、模型没变形、重复帧确定性。
