----------------------------------------------------------------

  * 萌娘百科「叶瞬光」「仪玄」条目：云岿山；仪玄「白衣白发、明黄色外套」；
    萌点含露指手套 / 符纸 / 臂环 / 发夹 / 斜刘海；叶瞬光中国风格、旗袍、短靴。
  * 360百科 / 互动百科：仪玄「明黄道袍」「道教元素 × 机能风」「腰悬符咒葫芦与玄鸟纹」。
  * 米游社《仪玄服装设计的那些小细节》（最具体）：明黄外袍领金乌纹、太极图案纽扣、
    坎水卦飘带挂象、符咒葫芦、长命锁腰带 + 挂穗。
  * 网易《品鉴叶瞬光》：「玄黑与静黄」、云纹、飘带（配色词与多源呼应）。
  * 3loumao 叶瞬光 cos 复刻文（中低可信，**只取结构**）：白/黄/黑三色拼接中式改良上衣、
    黄色立领盘扣、胸前黑布白叶印花、白发箍 + 红色几何角 + 花朵结、半指手套 + 银环镯。

**判为虚构，整篇不采信**：米游社《叶瞬光完整角色介绍》写「云岫阁 / 物理 / 长刀 /
CV 牟紫柔·石川绫乃」，与萌娘百科、官网角色表、其他百科的「云岿山 / 凛刃 /
青溟剑 / 陶典·M·A·O」全面冲突，是 AI 生成的同人设定。

**明确排除**：B站批评文 / PixAI 同人标签 / cos 站「仪玄黑亮皮衣」里的高开叉、
薄纱、off-shoulder、心形镂空、黑丝高跟、狐耳狐尾、二形态、青溟剑、黑皮衣 —— 
既与官方「白衣明黄道袍」矛盾，也违反项目从 V1 起守的中性全覆盖战斗服边界。

一句话：可迁移的不是某件衣服，而是「中式立领盘扣 + 白/明黄/玄黑三色拼接 +
外袍叠穿 + 道教金属挂饰 + 绳结流苏 + 国风与机能风叠层」这套结构语言。

**V4 看图结论**：
  达成 —— 脸模明显改善：V3 灰蓝瞳孔 + 细眼线 + 偏灰肤色 + 厚刘海遮眼，
  V4 是琥珀金分层虹膜（深外圈 / 亮内圈 / 高光）、清晰粗黑睫毛线、细眉、
  可辨鼻梁与唇形、干净肤色、刘海不遮眼。配饰密度显著上来：太极圆扣、红盘扣、
  腰间大圆扣 + 红流苏 + 金挂饰、银色大圆环耳环、半指手套 + 银环镯。
  仪玄线（金色滚边立领 + 明黄短披肩领）成立；V3 基底（云纹下摆 / 厚底靴 /
  电光青 / 无拳套）保留。

  **三处偏差，不粉饰**：
  1. 金色披肩是短袖，肩到肘整段裸露 —— 违反「仅脸与手露肤」的硬边界。
  2. 红色几何双角 + 白发箍 + 红色花朵结三件套几乎照搬叶瞬光标志头饰，
     逼近「不复刻具体角色」；而且工程师要求参考的是**上半身服装**，
     头部这套是我从 cos 复刻文里自己加的。
  3. prompt 写了黑色不对称襟片 + 白叶纹，实际生成白色圆襟片，
     叶瞬光那一半没落地，等于只实现了仪玄线。
