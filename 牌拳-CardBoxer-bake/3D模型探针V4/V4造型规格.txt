二、脸模优化（V3 的问题 → V4 的目标）
----------------------------------------------------------------
V3 服务预览的脸在 512² 图里只占约 40px，五官靠贴图糊在一起；
`立绘-front.png` 放大后眼线、虹膜层次、下颌线仍偏软。V4 目标：
  1. 杏形大眼，**分层虹膜**（深外圈 + 亮内圈 + 双高光点）、清晰上睫毛线、细眉
  2. 干净对称的鹅蛋脸、柔和但明确的下颌线、小巧鼻梁与鼻尖、淡唇形
  3. 肤色均匀无糊斑 / 无色块断层、不做次表面柔光把五官洗平
  4. 层次碎刘海 + 鬓角修饰脸型，单侧长马尾保留
  5. **头身比维持 V3**（不 Q 版、不拉成写实成人比例），表情冷静专注
判据：渲 1024² 头部特写，与 V3 同尺度 4× 并排，靠看图判；脚本不评「好看」。


三、上半身服装结构（参考两位角色，只取结构语言）
----------------------------------------------------------------
  1. 中式**立领**，暖金 / 明黄滚边（叶瞬光黄立领 + 仪玄明黄外袍领）
  2. **短外袍式披肩领**叠在肩上，形成白主色 + 明黄外层 + 玄黑内襟的三色拼接
  3. 胸前**黑色不对称襟片** + 白色叶片 / 云纹印花（叶瞬光），抽象几何化处理
  4. **红盘扣保留**（V3 基底），加一枚**太极纹圆扣**作主扣（仪玄）
  5. 领口**金乌 / 玄鸟几何纹**（仪玄），只作纹样、不做阵营徽记
  6. 收腰硬朗走线 + 银色细边，与 V3 都市机能层接上
  7. 下摆靛蓝云纹带、不对称下摆、深靛蓝长裤、厚底靴 —— **V3 原样保留**

四、配饰清单（本轮「优化配饰」的落点）
----------------------------------------------------------------
  头：白色发箍、一对红色几何小角、侧边花朵结 / 发夹、银色小耳环（电光青点缀保留）
  领：领夹 + 太极圆扣
  胸：绳结、流苏、小型符牌挂饰、金属扣件
  腰：长命锁形腰牌 + 挂穗、小葫芦挂件；V3 机能腰包与斜跨胸带**退为次层**
  手：半指 / 露指布缠手带、银色环镯 ×2、深色护腕（**仍然无拳套**）

五、合规与边界（延续 V1~V3，不撤销）
----------------------------------------------------------------
  * 只取服装结构与配色关系，**不复刻任何具体角色**：不写角色名、阵营名、
    徽记、Logo、UI、武器（青溟剑等）、狐耳狐尾、二形态。
  * 中性**全覆盖**战斗服：仅脸与手露肤；不画露肩、高开叉、薄纱、心形镂空、
    黑丝高跟。搜索结果里这类描述多来自同人 / 性化二创，本来也不该采。
  * prompt **完全不出现 glove / boxing**（连否定式也不写，V2 踩过语义簇跑偏）。
  * 保持 Neutral A-pose / 单角色 / 头到脚 / 居中正面 / 无底座 / 无武器 /
    无背景 / 无文字 / 均匀打光，保证 V1~V4 服务预览可直接对比。
  * 生成模型仍预期是静态单 mesh / 0 skins / 0 animations（V1 861、V2 1045、
    V3 1557 连通壳，自动绑骨 0 覆盖）。**本轮不解决这个结构问题**，
    不渲 228 帧图集，不导入 Godot。

六、prompt 决策

    check_prompt.py 自动核对，不靠肉眼。

    三稿 1212 → 1051 → 1014；check_prompt.py 五项全过（长度 / 禁词 /
