4. 坐标口径与 pose 基底（本轮最容易错的地方）
========================================================================
由 `data/godot_rig_probe.json` 实测确定，不靠猜：

  Godot (X, Y, Z) = Blender (x, z, -y)      [export_yup=True]
  apose_points[u] = (hx, hz)_Blender -> hv = (hx, hz, 0)_Godot
  RotY(theta)_Blender == RotZ(-theta)_Godot  -> theta 必须取负
  Blender: pb.matrix = D[name] @ bone.matrix_local
           D[name] = D[parent] @ local
           local = T(hv) @ R @ T(-hv)（绕 A-pose 关节点的全局增量旋转）

**Godot 4 的 bone_pose 初值 == local_rest**，即 pose[i] 是
「相对父骨的绝对变换」，不是「相对 rest 的增量」：

  global_pose[i] = global_pose[parent] @ pose[i]
  令目标 global_pose[i] = D[i] @ GR[i]：
    pose[i]     = GR[parent]^-1 @ local[i] @ GR[i]     （非根骨）
    pose[root]  = D[root] @ GR[root]                   （根骨含 root 平移）

第一版写成 `GR[i]^-1 @ local @ GR[i]`，把 pose 做成相对本骨 rest 的
增量，**引擎骨架完全不动**（不是动得小，是零）。基底是**父骨**的
global_rest，不是本骨的；这条已钉进 A04 判据并有 M02/M03 变异守着。

第 14 根 `neutral_bone` 是 glTF 导入器生成的独立根骨，**不参与驱动**；
它的初值不是 identity（约 -90° X 旋转），第一版拿 identity 当基准误报过
一次。判据 C10 要求驱动前后该骨 pose 逐字不变。

9. 踩坑清单（可复用）
========================================================================
① **pose 基底**：见第 4 节。`GR[i]^-1` → 引擎骨架完全不动；
   正解是父骨的 `GR[parent]^-1`。
② **Z 轴符号**：`RotY(theta)_Blender == RotZ(-theta)_Godot`，
   theta 取负；A05 专门钉这条，M01 变异守着。
③ **neutral_bone 初值不是 identity**（约 -90° X 旋转），
   拿 identity 当「未动」基准会误报；它也不参与驱动。
④ **`--script` 启动不扫全局类缓存**：不能依赖 `class_name` 全局注册，
   主场景用 `preload("res://scenes/rig_driver.gd")`，探针同口径。
⑤ **引擎内截帧必须带窗口**：headless dummy driver 不发
   `RenderingServer.frame_post_draw`（D 路线结论，F 沿用）。
⑥ **重复帧口径**：EEVEE / 8-bit 量化会有 ±1 抖动，判据用
   「字节完全相同」与 `changed_px(>6)` 下限，不要求肉眼零差。
⑦ **清单自指 + 验证记录进清单**：写死条目数当场过期；
   用动态覆盖检查 + 可复算命令，排除 logs / .godot。
⑧ **变异锚点失配 = 未证明**：CRLF + `indent=2` 会让单行 needle
   匹配 0 次而脚本照样打印「全绿」；`DID NOT RUN` 必须计入未证明，
   且要有 selftest 证明这个分支真的会响。
⑨ **glTF 里 SURFACE_DEFORM 无对应物**：想让 Godot 动高模，
   必须在 Blender 侧把权重烘进高模的 vertex group 再导出，
   不能指望 modifier 跨格式活下来。
