V4b 修正说明（在 V4 基础上，只改三处，不动已成功的部分）
================================================================
触发：V4 同相机对照看图后，发现三处必须修的偏差。

一、V4 达成了什么（保留，不推翻）
----------------------------------------------------------------
  * 脸模：**明显改善**。V3 是灰蓝瞳孔 + 细眼线 + 偏灰肤色 + 厚刘海遮眼；
    V4 是琥珀金分层虹膜（深外圈 / 亮内圈 / 高光）、清晰粗黑睫毛线、
    细眉、可辨鼻梁与唇形、干净白皙肤色、刘海整齐不遮眼。
  * 配饰密度：太极圆扣、红盘扣、腰间大圆扣 + 红流苏 + 金色挂饰、
    银色大圆环耳环、半指手套 + 银环镯、白发箍 + 花朵结，全部落地。
  * 上半身仪玄线：金色滚边立领 + 明黄短披肩领（明黄外袍的落地）成立。
  * V3 基底保留：靛蓝云纹下摆、不对称下摆、厚底靴、电光青点缀、无拳套。

二、三处偏差（本版修正目标）
----------------------------------------------------------------
  1. **上臂裸露**：V4 金色披肩是短袖，肩到肘整段肤色外露，违反项目
     从 V1 起守的「中性全覆盖战斗服，仅脸与手露肤」。
     -> 加 `full-length fitted sleeves, arms fully covered`，并前置到覆盖约束句。
  2. **头部配饰太贴叶瞬光**：红色几何双角 + 白发箍 + 红色花朵结三件套
     几乎是该角色的标志头饰，逼近「只取结构语言、不复刻具体角色」边界。
     工程师要求参考的是**上半身服装**，头部这套是我从 cos 复刻文里自己加的。
     -> 改成 `two small red hair clips, small side flower clip`，只留通用发夹语义。
  3. **叶瞬光线没落地**：V4 prompt 写了 `black asymmetric front panel,
     white leaf-cloud print`，实际生成的是白色圆形襟片，黑色不对称襟片
     与白叶印花都被金色披肩挤掉了；等于上半身只实现了仪玄那一半。
     -> 改成 `black asymmetric chest panel with white leaf print`，
        移到服装句更靠前的位置并去掉 `with` 从句减弱权重。

三、为了腾字符砍掉什么（V3 教训：只砍修饰词，不砍造型层）
----------------------------------------------------------------
  砍 `small sunbird collar motif`（V4 没生成出来）、`charm tag`（同上）、
  `even skin`（脸模已达标）、`Matte black chest strap`（缩成 `Black utility belt`）、
  `short`（cape collar）、`band`（cloud hem）。
  脸模句、太极扣、绳结流苏、长命锁腰牌、手部、云纹、靴子、A-pose 与
  全部必备约束**一个没动**。

四、口径不变
----------------------------------------------------------------
  仍 ≤1024 字符；仍完全不出现 glove / boxing / 具体角色名 / 阵营名；
  仍是静态 A-pose 探针，不解决 0 skins / 0 animations / 开放壳问题；
  不改游戏源码、不导入 Godot、不渲 228 帧图集。
  V4 全部产物保留在 `3D模型探针V4/`，本版独立目录，两版可并排选。
